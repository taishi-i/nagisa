# Security Policy

## Supported Versions

Security fixes are provided for the latest release only.

| Version | Supported |
| ------- | --------- |
| 0.3.x   | ✅        |
| < 0.3   | ❌        |

The latest release supports Python 3.10 - 3.15.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, pull requests or discussions.

Instead, report them privately via GitHub's
[private vulnerability reporting](https://github.com/taishi-i/nagisa/security/advisories/new)
(the **Security** tab → **Report a vulnerability**).

Please include as much of the following as you can:

- A description of the vulnerability and its impact
- The affected version of nagisa, Python version and OS
- Steps to reproduce, or a proof of concept
- Any suggested fix, if you have one

You will receive an initial response within 24 hours.
If the issue is confirmed, a fix will be released and a security advisory published,
crediting you unless you prefer to remain anonymous.
